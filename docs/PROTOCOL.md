## 参照範囲

A〜J の10系統は、共通の研究課題・プロトコルと自分自身の履歴だけを参照します。兄弟系統の数学内容と K の数学的内容を入力に戻しません。K は各ラウンドの全系統の完了原文と自分の履歴を参照し、統合探索を進めます。K 向け入力は全系統のレビュー完了後に凍結し、進行中の枝を読みません。

## ラウンドの完了条件

ラウンド0では課題を解釈し、必要な定義・仮定・先行研究を取得します。実際に読んだ箇所と、単に入手可能な文献を分け、書誌情報と参照箇所を残します。網羅的な文献調査の完了を意味しません。

以後は有限の命題群を対象とし、証明、例、反例、または具体的な未解決障害を記録します。定理の発見は必須条件にしません。独立した新しい文脈の AI レビューで、証明・関連性・仮定・新規性を別々に調べます。判断は valid / qualified / gap / false / unresolved を使い、誤りと修正履歴を残します。各系統のレビューが揃ってから次の周回へ進みます。

時間制限や文章量ではなく、対象の検討・レビュー・記録の完了で区切ります。所要時間が残っていても、それを数学的な品質保証とは扱いません。
