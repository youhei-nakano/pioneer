# 公開範囲と残る判断事項

## 採用したもの

新しく書いた README、プロトコル、実装調査、再現性・限界の文書、縮小した有限計算例とその期待結果だけを採用します。公開例の由来は隣の README に記載しました。第三者パッケージのコードや文献本文を同梱していません。

## 除外したもの

- 原文アーカイブ全体、転送用 JSON / gzip / base64、受信メッセージ、内部実行ログ。
- 認証情報、個人情報、メッセージID、ローカル絶対パス、非公開の実行環境情報。
- 原本への書き込みを前提にする記録生成・梱包コード、未確認コード。
- キャッシュ、バイトコード、失敗時のスタックトレース、環境固有のメタデータ。
- 他者文献の長い転載、図版、PDF、第三者のライセンス未確認コード。
- 進行中の後続ラウンド、旧探索の内容、公開例で検証していない数学的主張の原文。

.gitignore は誤追加を減らす補助です。秘密情報の検出器でも、すでに追跡されたファイルの除外機構でもありません。

## 判断を保留したこと

ライセンスは未選択です。コードと研究文書にどの利用許諾を付与するか、著者表記、第三者由来の確認、引用形式、今後の原文公開範囲は別途決めます。現在の公開は全文アーカイブの公開許可を意味しません。

今後、汎用ランナーを提供するかは未決定です。自動化する場合のモデル・費用・権限・停止条件も、この版では決めていません。

## Skill 追加

`skills/pioneer` と合成プロトコル検証記録を追加しました。研究の再開、新しい研究成果、原文記録の追加公開、汎用ランナーの実装は含みません。ライセンスは引き続き未選択です。
