## 読み取り調査で確認したこと

ラウンド7の338件の凍結集合には Python ファイルが 56 件あります。コピー・失敗試行・記録生成用も含む件数で、独立した機能数ではありません。全件を構文解析し、うち選抜候補の数学計算と初期の梱包スクリプトを本文まで確認しました。元スクリプトは一切実行していません。

| 実在するもの | 証拠の例 | 再利用判断 |
| --- | --- | --- |
| 数学の有限計算 | C/round7/check_examples.py、H/round7/verify_systems.py | 特定の代数的主張の計算例。一般の研究探索器ではない |
| レビュー側の計算 | A/round7/review_001/independent_checks.py など | 個別の検査コード。全件の安全性・実行環境は未検証 |

指定した現行・旧記録ルート直下に .git はありませんでした。既存の Git 履歴や remote は変更していません。関連する祖先・記録内に AGENTS.md は見つからず、ユーザーの .agents/skills の一覧と日本語文書スキルの内容を読み取り確認しました。旧記録は存在と構成のみ確認し、新しい公開例の根拠には使用していません。

## この公開版の推奨構成

README、docs、examples の小さな研究記録プロジェクトとして始めます。原本と運用環境に依存するスクリプト、API接続、エージェント制御、秘密情報は取り込みません。実行できるものは examples に限定し、由来と計算範囲を隣に書きます。
