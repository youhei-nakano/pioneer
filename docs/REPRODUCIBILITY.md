# 再現性

## 再実行できる範囲

公開例は Python 標準ライブラリによる厳密な有理数計算です。乱数、モデルAPI、ネットワーク、外部依存を使わず、同じ JSON 出力を期待できます。成功時の結果は examples/subset-sums/expected.json にあります。assert を検査に使うため python -O は使用しないでください。

この例の再現は、元の AI 探索過程の再現とは異なります。モデル、プロンプト全文、ツール応答、文献取得状態、実行環境を公開しておらず、探索全体を同一に再実行する手順は提供していません。プロトコルは運用を説明する文書であり、自動実行コマンドではありません。

## 原本の同一性を確かめた範囲

準備時にラウンド7の凍結集合338件を SHA-256 で照合しました。336件は保存済みファイルのバイト列、2件の Python バイトコードは補足 JSON の base64 をメモリ上で復号して照合しました。バイトコードは実行も公開もしていません。K6 は k_checkpoint_013 の complete_file_manifest.json に列挙されたファイルを照合しました。これはスナップショット内の全履歴の独立再監査ではありません。

公開用に書き直した例と文書には元のハッシュを流用していません。公開版自身のファイル一覧とハッシュは SHA256SUMS に記録します。秘密情報のパターン検査だけでは漏えい不存在を証明できないため、採用ファイル本文も確認します。

## Skill の再現性

`skills/pioneer` は実行手順のパッケージです。モデル接続や隔離・ラウンド制御を実装しません。構造検証と小さな合成入力による判断の確認は `docs/SKILL_VALIDATION.md` に記載します。これは実研究の再現や数学的検証とは異なります。SHA256SUMS は自身を除く追跡対象の公開ファイルを列挙します。
