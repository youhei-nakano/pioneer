# 正の有理数の部分和多重集合を復元する縮小例

由来：ラウンド7の C 系統の check_examples.py にある sums / recover と部分和復元の有限検査を読み、標準ライブラリだけで動く形に書き直しました。参照した原文は checkpoint_125 の凍結スナップショットに保存された C/round7/check_examples.py です。その SHA-256 は SOURCE.json に記録しています。元の全ファイルや数式の主張を転載したものではありません。

正の重みのリストから全ての部分集合の和を、多重度を保って列挙します。空集合の0を一つ除くと、最小の未処理要素は次の重み候補になります。既知の部分和にその重みを足した多重集合を差し引く操作を繰り返します。重複重みと、異なる部分集合が同じ和を作る場合も残します。

候補重み {1/3, 1/2, 2/3, 1, 3/2}、長さ0〜7の全792リストを検査します。さらに (1,3) と (2,2) は部分和総和が同じ8でも多重集合は異なることを確認します。スカラー一つへの圧縮で情報を失う小さな反例です。

正値という仮定は必要です。重み0を含むと最小未処理要素が正という条件に反し、この実装は拒否します。これは入力の境界を示す検査であり、元の研究における全ての反例・修正履歴の代わりではありません。

原文は SymPy による正則表現のトレース、Smith 標準形、行列増幅なども調べています。この縮小例ではそれらを実装・検証していません。一般の実数付値や幾何学、新規性も検証対象外です。

実行：リポジトリ直下で `python3 examples/subset-sums/check.py`。出力は expected.json と一致します。
