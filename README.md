# pioneer

定義や問いを出発点に、複数の独立系統と統合系で命題・証明候補を探索し、独立 AI レビューを記録する実験プロジェクトです。統合探索系 K と独立レビュアーは別の役割を担います。今回の公開スナップショットで扱う実験テーマは「トーリック多様体上の深谷圏の A∞ 代数の幾何学的な意味」です。この公開版では、探索の進め方、限界、再実行できる小さな有限計算例を示します。

**汎用の探索ランナーは、この公開版には実装されていません。** 元の記録には個別の数学計算・記録作成・チェックポイント梱包用 Python スクリプトが存在しますが、任意の研究課題を自動実行できるシステムとしての再利用は未検証です。

## 読む順序

- [実装調査と推奨構成](docs/IMPLEMENTATION.md)：確認したコードと今後の実装を区別。
- [再現性](docs/REPRODUCIBILITY.md)：何を再実行できるか。

- [公開範囲と判断事項](docs/PUBLICATION.md)。

## 小さな計算例を実行する

Python 3.10 以上、標準ライブラリのみを使います。リポジトリ直下で実行します。

```sh
python3 examples/subset-sums/check.py
```

成功時は JSON が標準出力に出ます。原本や外部サービスへのアクセス、ファイル書き込みはありません。

## 記録の基準

A〜J はラウンド7完了の凍結記録（338ファイル、checkpoint_140 と checkpoint_141）、K は k_checkpoint_013 の K6 完了記録を基準にしました。338件はラウンド7の凍結集合の件数であり、全ラウンドの総件数ではありません。後続の進行中ラウンドと旧探索は公開版の成果に混ぜていません。

原文アーカイブの一括コピーは含みません。公開例は凍結記録の一部をもとに新しく書き直した縮小例で、原文そのものではありません。AI レビューは形式検証でも人間の査読でもなく、研究の新規性は未確認です。
